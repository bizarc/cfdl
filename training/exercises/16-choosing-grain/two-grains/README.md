# The same deal, twice

1. Run the monthly starter. Note the NPV.
2. Rebuild the deal at annual grain: a two-period grid, each stream stating twelve-month totals. Project fees exist only in year two.
3. Predict the direction of the NPV gap before the second run.
4. Run, and measure the gap.

The lifetime total must match exactly — 288,000, both ways. The NPVs will not. The annual model's cash sits at each year's end and discounts the full year; the monthly model's cash arrives spread across it. The gap is what "rolling up is free, slicing down is fabrication" is worth in dollars on even this tiny deal. The annual model did not simplify the timing — it *changed the claim*.
